# 信贷数据集说明文档
## 1. 数据集来源
公开数据集 Kaggle Give Me Some Credit
数据集下载地址：https://www.kaggle.com/c/GiveMeSomeCredit/data
> 说明：原始csv文件体积较大，不存入本Git仓库，仅留存文档说明，本地练习自行下载使用。

## 2. 业务模拟场景
模拟国有六大行零售信贷业务：信用卡循环贷、线上消费信用贷客户样本，覆盖贷前申请、贷中行为监控、贷后逾期追踪全流程，贴合风控数据、风险策略、风险监控岗日常分析场景。

## 3. 核心字段含义（银行信贷业务释义）
| 字段名 | 业务含义 | 风控用途 |
|--------|----------|----------|
| SeriousDlqin2yrs | 目标标签：未来2年内是否发生严重逾期（1=发生违约，0=正常） | 建模预测目标，对应FRM中PD违约概率测算 |
| RevolvingUtilizationOfUnsecuredLines | 无担保循环贷额度使用率（信用卡负债/授信总额） | 客户负债压力特征，高占比代表高信用风险 |
| age | 客户年龄 | 客户分层、客群划分基础特征 |
| NumberOfTime30-59DaysPastDueNotWorse | 近2年逾期30-59天次数 | 历史轻度逾期行为特征，用于行为评分卡 |
| DebtRatio | 月债务支出/月收入比例，负债收入比 | 客户长期偿债能力核心指标 |
| MonthlyIncome | 客户月收入 | 还款能力基础变量，建模前做异常截断处理 |
| NumberOfOpenCreditLinesAndLoans | 现有信贷账户总数量（信用卡+消费贷） | 客户信贷活跃度、多头借贷识别特征 |
| NumberOfTimes90DaysLate | 近2年逾期90天及以上次数 | 重度逾期核心风险特征，高权重预警指标 |
| NumberRealEstateLoansOrLines | 房贷/不动产贷款数量 | 区分有无固定资产客户，资产负债结构分层 |
| NumberOfTime60-89DaysPastDueNotWorse | 近2年逾期60-89天次数 | 中度逾期行为特征，贷中风险预警依据 |
| NumberOfDependents | 家庭赡养人数 | 家庭偿债压力辅助特征 |

## 4. 本项目数据使用规范
1. 数据清洗流程：缺失值填充、极端收入/负债异常截断、逾期次数上限封顶；
2. 特征衍生方向：近半年累计逾期次数、负债分层、额度使用率WOE分箱；
3. 建模用途：搭建申请评分卡、行为评分卡，输出AUC、KS、PSI完成模型月度稳定性监控；
4. 业务理论联动：结合FRM一级信用风险计量模块，测算存量零售资产预期损失EL、客户逾期迁徙矩阵，贴合巴塞尔零售内评监管要求。
